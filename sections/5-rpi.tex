\section{Infotainment computer software}

The infotainment computer is a Raspberry Pi 4 with a DSI touchscreen display. It's running a custom Linux
distribution built with the Yocto build system. The graphical application is written using C++ and the Qt
framework. This software is not the focus of this assignment and will not be covered in depth.

\begin{figure}[H]
  \begin{center}
    \includegraphics[width=0.75\textwidth]{images/1-rpm.png}
    \caption{Screenshot of an early version of the software.}
  \end{center}
\end{figure}

\noindent
Features:
\begin{itemize}
  \item Basic live telemetry. (Engine RPM and temperature, vehicle speed, fuel status)
  \item Vehicle information. (Door status, trip computer)
  \item Radio information. (Station information, CD player information)
  \item Local music player.
  \item Bluetooth player.
\end{itemize}
